# M4 UI Compatibility

M4 keeps the established M3 dashboard layout and interaction order. Strategy-driven ranking is integrated into the existing approval workflow rather than introducing a new dashboard section or moving the holdings, metrics, history, or footer.

## UI contract

- Preserve the existing top bar, hero, four metric cards, notice area, Human approval gate, Holdings table, snapshot metrics, and audit trail in the same order.
- Add strategy-driven decisions inside the existing Human approval gate.
- Keep the visible refresh countdown and manual refresh control in the existing top bar.
- Keep human approval mandatory; auto-approval and broker execution remain disabled.
- Do not redesign the dashboard when adding future strategy capabilities; extend existing panels first.
