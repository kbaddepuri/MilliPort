# MilliPort

**Intelligent Portfolio Growth Engine**

MilliPort is a production-oriented portfolio intelligence platform for turning a disciplined starting portfolio into a data-driven path toward $30K, $100K, $200K, $500K, $1M, $2M, $5M and beyond.

## Core principle

MilliPort expresses actionable portfolio decisions in dollars:

- `BUY $X`
- `HOLD $0`
- `WATCH $0`
- `SELL $X`
- `EXIT $X`

## V4

V4 is the first production-oriented implementation. It will evolve from portfolio tracking into a real decision engine using market data, portfolio context, fundamentals, valuation, momentum, catalysts and risk.

## Roadmap

1. Foundation — architecture, domain model and engineering conventions
2. Portfolio MVP — holdings, prices, target tracking and dollar-sized actions
3. Intelligence engine — scoring, catalysts, valuation, risk and opportunity ranking
4. Live product — persistence, scheduled refresh, alerts and production deployment

## Current mission

Initial portfolio: approximately **$16.47K**.

Near-term target: **$30K**.

Investment decisions surfaced by MilliPort should be traceable to the underlying data and scoring rationale.
